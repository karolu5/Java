# Java Fundamentals

A collection of Java programming exercises focused on strengthening my knowledge of core Java concepts, problem-solving, and object-oriented programming.

This repository documents my learning progress through practical exercises, from basic syntax to working with classes and collections.

## Topics covered

- Java syntax and data types
- Variables and operators
- Conditional statements
- Loops
- Methods and code organization
- Arrays
- Classes and objects
- Encapsulation
- ArrayList and basic collection operations

## Exercises

| Exercise | Description |
|---|---|
| Hello World | Introduction to Java syntax |
| Variables | Practice with basic data types |
| Conditionals | Decision-making with conditional statements |
| Loops | Repetition using loops |
| Calculator | Console calculator using control structures |
| Calculator Methods | Calculator organized into reusable methods |
| Student Grades | Working with arrays and student grades |
| Student System | Practice with classes, objects and encapsulation |
| Student List | Managing multiple students using ArrayList |
